第一，我学习东西比较愿意从基础开始，不太喜欢只看表面的概念。比如我最近在学大模型应用，不只是学怎么调用 API，也会去理解结构化输出、工具调用、RAG 检索流程、Agent 循环控制这些基础模块。这样后面做项目的时候，出问题也比较容易定位。

### 介绍项目
第一个是 Mjcode Coding Agent，是一个终端 AI 编程助手，主要体现的是 Agent 工程能力。它基于 ReAct 和 Plan-and-Solve 两种模式，让模型能够调用文件、命令行、搜索等工具完成编程任务。我在里面设计了交互、引擎、工具、记忆、安全五层架构，也做了 MCP 工具按需加载、跨会话记忆、多 Agent 协作和安全拦截机制。
第二个是 Spec2Control，这个和工业场景更相关。它面向工业自动化控制逻辑生成，目标是把自然语言控制需求转换成 FBD 功能块图，并导出成 OpenPLC 可以识别的 PLCOpen TC6 XML 文件。项目流程包括控制语义抽取、功能块识别、控制逻辑生成、结构化解析、XML 导出和自动布局。后续我计划引入多 Agent 协作，把生成、校验、修复做成闭环，提高控制逻辑生成的可靠性。
这两个项目一个偏 Agent 工程能力，一个偏工业控制场景，我希望后续能把两者结合起来，把 Agent 技术用于制造业真实业务，比如工业文档理解、控制逻辑辅助生成、数据分析和智能制造辅助决策。，使结果可以导入 OpenPLC Editor 进行可视化验证。
