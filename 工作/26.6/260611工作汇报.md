### 1.了解 Spec2Control 项目的基本工作流程：它如何把文字形式的控制要求，转换成功能块图。
工业自动化项目里，客户常用自然语言写控制叙述，例如说明泵、阀门、传感器、报警、联锁、控制策略应该怎样工作。传统做法是控制工程师手工阅读这些文字，再在 PLC工程工具里搭建 IEC 61131-3 功能块图。Spec2Control 的目标是把这个过程尽可能自动化：先把文字切成可处理的小段，识别需要哪些功能块和控制策略，再让 LLM 生成一种文本形式的 FBD 中间表示，最后用确定性程序把它转成 PLCOpen XML，并自动布局成 OpenPLC 等工具能打开的功能块图。
大概流程为
control narrative -> narrative chunk-> context generation result
-> textual FBD pseudo-code-> PLCOpen XML-> graphical FBD in PLC IDE
对应到代码层，大概流程为
```
data/control-narratives/<name>/<name>.md
  -> src/spec2control_cli.py
  -> data/prompt-sets/contextgen.txt
  -> chapter_N/1_categorization.txt
  -> data/prompt-sets/openplc-fbd.txt
  -> chapter_N/2_control_logic.txt
  -> src/export_openplc.py
  -> chapter_N/SectionN.xml 和 plc.xml
```
