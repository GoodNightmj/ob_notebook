
## 第 2.5 节 从正则表达式到非确定有限状态自动机的转换：Thompson 算法

前面的章节介绍了正则表达式与有限状态自动机（Finite Automata，FA）的基本概念。正则表达式能够形式化地定义程序语言中词法单元的结构，而有限状态自动机（尤其是非确定有限状态自动机，Non-deterministic Finite Automata，NFA）则是一种可执行的结构，适合实际进行词法识别任务。然而，要使正则表达式真正用于驱动词法分析器的自动生成，首先必须将正则表达式转换为相应的有限状态自动机。这一转换的核心方法就是著名的**Thompson算法**。

### 2.5.1 转换过程概览与重要性

正则表达式（RE）本身是一种声明式的规范，用于定义语言词法元素。但要生成实际的词法分析器程序，需要将这种声明式规范转化为过程性的结构，即自动机（特别是DFA）。由于直接从正则表达式到DFA的转换难以直接实现，因此实际采用的方法是：

```
正则表达式 → NFA → DFA → 词法分析器代码
```

在这一流程中，从正则表达式到非确定有限状态自动机（NFA）的转化是关键的第一步，也是编译原理中极其经典的一个过程。Thompson 算法正是实现这一转化的经典方法，由 Ken Thompson 提出。Thompson 是著名的计算机科学家、Unix操作系统的创始人之一，他因为 Unix 和 C 语言的贡献获得了1984年的图灵奖。Thompson 算法以他名字命名，反映了他在形式语言处理领域的重要贡献。

### 2.5.2 Thompson 算法的基本思想与特点

Thompson 算法是一种基于递归构造思想的算法，其核心思想是：

- 对于**基本形式的正则表达式**，即空串（ε）和单个字符（c），直接构造对应的NFA。
  
- 对于**复合形式的正则表达式**，即连接（Concatenation）、选择（Alternation）和闭包（Kleene Closure），则递归地利用子表达式构造NFA，再组合起来形成整体的NFA。
  

正是由于这一递归的特性，Thompson算法的代码实现通常非常简洁优雅，易于维护和理解，整个算法的实现往往不到百行代码。

### 2.5.3 基本正则表达式的 NFA 构造（基础情形）

我们首先介绍基础情形，即如何为最简单的正则表达式构造NFA：

#### （1）空串（ε）的NFA构造

对于空串ε，我们直接构造一个仅包含两个状态的自动机：

- 有一个起始状态（标记为起始），一个接受状态（标记为接受）。
  
- 两个状态之间用一条标记为ε的转换边连接。
  

该结构代表从起始状态不消耗任何字符即可到达接受状态。

#### （2）单个字符（c）的NFA构造

类似地，对于单个字符c：

- 创建一个起始状态和一个接受状态。
  
- 起始状态到接受状态之间有一条标记为c的转移边。
  

此结构明确表示仅识别单字符c的自动机。

### 2.5.4 复合正则表达式的 NFA 构造（递归情形）

下面是三种复合正则表达式的构造方法。对于这些情况，本文假设子表达式的NFA已递归构造完毕：

#### （1）连接表达式（Concatenation）

给定正则表达式 `e1e2`，构造步骤为：

- 分别构造子表达式 `e1` 和 `e2` 对应的NFA，设为 NFA(e1) 和 NFA(e2)。
  
- 将 NFA(e1) 的接受状态通过一条ε边连接到 NFA(e2) 的起始状态。
  
- 最终自动机的起始状态为 NFA(e1) 的起始状态，接受状态为 NFA(e2) 的接受状态。
  
- 删除原有接受状态和起始状态的属性标记。
  

注意：一般在实现中不合并状态，尽管理论上可行，这主要为了代码实现简洁。

#### （2）选择表达式（Alternation）

给定表达式 `e1 | e2`，构造方式为：

- 分别构造子表达式NFA(e1)和NFA(e2)。
  
- 新增一个起始状态和一个接受状态。
  
- 新起始状态分别用ε边连接到 NFA(e1)和NFA(e2)的起始状态。
  
- NFA(e1)和NFA(e2)的接受状态各自通过ε边连接到新的接受状态。
  
- 移除NFA(e1)和NFA(e2)原接受状态和起始状态的属性。
  

#### （3）闭包表达式（Kleene Closure）

给定表达式 `(e1)*`，构造方式如下：

- 构造子表达式 e1 的 NFA。
  
- 新增一个起始状态和接受状态。
  
- 新起始状态直接通过ε边连接到新的接受状态，以表示零次的情况。
  
- 新起始状态通过ε边连接到 e1 的起始状态；e1 的接受状态再通过ε边回到 e1 的起始状态，形成循环，用以表示多次重复的情况。
  
- e1的接受状态也通过ε边连接到新的接受状态。
  
- 移除 e1 原接受状态和起始状态属性。
  

### 2.5.5 一个具体实例：完整的构造过程

本文以正则表达式 `a(b|c)*` 为例，说明完整的构造过程：

- 从最外层看，这是一个连接表达式，其中左侧是单字符a，右侧是一个闭包表达式 `(b|c)*`。
  
- 递归地构造单字符 a 的 NFA（两个状态，一条边）。
  
- 再递归地构造闭包表达式 `(b|c)*` 的NFA：
  
    - 首先构造选择表达式 `b|c` 的NFA。
      
    - 然后按照闭包结构，增加起始、接受状态和循环ε边。
    
- 将单字符a的NFA和闭包NFA通过ε连接，完成整体NFA。
  

最终形成的NFA状态图体现了Thompson算法的递归组合特性，结构清晰易于实现。

### 2.5.6 Thompson 算法的特性与优势

Thompson 算法最大的优势在于其简单性与优雅的递归结构。它避免了复杂的状态合并和冲突消解，使得构造过程极为清晰和易于实现。事实上，大多数正则表达式引擎（如Unix下的grep）都在某种程度上借鉴了Thompson算法的思想。

由于Thompson算法生成的NFA可能状态数较多，因此下一步我们通常需要通过子集构造法将其转换为等价的确定性有限自动机（DFA），从而提高后续词法分析的效率。
