# XiUOS: an open-source ubiquitous operating system for industrial Internet of Things

- **主旨**：宣布并概述一个面向工业物联网（IIoT）的 **UOS（泛在操作系统）实例** —— **XiUOS** 的开源发布、定位、体系结构与早期应用，强调其为智能制造车间提供“感知-联网-认知-控制”的一体化软件底座。

## 背景：HCPS、UOS 与 IIoT 的关系

- **HCPS（人-网-物融合系统）**：在传统 CPS 基础上把“人”纳入系统要素，强调万物数字化、网络化、智能化与 **计算的泛在化**。
    
- **为什么需要 UOS**：HCPS 的应用对操作系统能力提出超出现有通用 OS 的新需求，因此提出 **UOS（Ubiquitous OS）** 概念，面向不同场景提供不同的 UOS 实例。
    
- **智能制造中的 IIoT**：在车间里把设备/人/网络贯通，以低成本、可持续的方式实现数据获取、预测性维护与按需控制，需要一个易裁剪、可落地的 **IIoT 平台/OS**。
    
    117101
    

## 现有 IIoT 平台的梳理与痛点

- **通用型平台**（软件公司主导）：如 Azure IoT、AWS IoT、阿里云 IoT 等偏重云侧数据管理；Cumulocity 强设备管理；Watson IoT 偏分析；ThingWorx 较全面。
    
- **行业型平台**（设备厂主导）：如西门子 MindSphere、博世 IoT Suite、ABB Ability、海尔 COSMOPlat，常与通用组件配合。
    
- **中国工厂的现实困难**：设备数字化水平低、预算有限、IT 基础薄弱、需求复杂，急需 **开源、可裁剪、面向车间落地** 的 IIoT 方案。

## XiUOS 的体系结构与特性（Figure 1）

**四层架构：硬件层 → 内核层 → 框架层 → 应用层**

1. **硬件层**
    

- 传感器：温/湿度、烟雾、气味、噪声、电流/电压等，支持相机、麦克风；
    
- 通信：5G/4G、Wi-Fi、NB-IoT、LoRa、以太网、ZigBee；
    
- 处理器：ARM、RISC-V；**已在 7 块开发板与 QEMU 上运行**。
    

2. **内核层**（“可扩展、高效、极简”内核）
    

- **实时任务调度**；
    
- **内核态/用户态隔离**；
    
- **动态+静态混合内存管理**；
    
- POSIX 友好。
    

3. **应用框架层（核心）**：围绕 “**感知（Sensing）- 联网（Networking）- 认知（Knowing）- 控制（Controlling）**”
    

- **感知**：提供 **面向物理量的编程模型**，统一驱动安装、数据解析/采集/管理，降低写传感程序的难度；
    
- **联网**：集成常用协议栈与消息库（如 **MQTT**），规划支持 **无线 Mesh** 以简化车间网络管理；
    
- **认知**：提供 **轻量 AI 引擎** 与算法加速库；**1.0 已能做仪表盘识别**，**2.0 计划支持语音/目标/人/缺陷模式识别**，面向资源受限设备；
    
- **控制**：内置 **PLC 控制库**，可从 **西门子/欧姆龙/B&R** 等 PLC 采集数据，实现 **远程精确控制**。
    

4. **应用层**：环境监测、工控视觉、看板识别、电力监测、目标识别等应用。  
    **在研配套**：HAL、**OTA**、**轻量实时数据库**、**MicroPython** 等。

## 版本节奏与能力边界

- **1.0（已发布）**：已具备基础 **感知与联网** 能力，并有初步的 **智能分析与告警控制**。
    
- **2.0（计划于 2021-12）**：完整落地“感知-联网-认知-控制”一体框架，带来“便捷数据获取、易连接、预测性维护、按需控制”的系统性收益。_（注：这是文中当时的计划说明）_
