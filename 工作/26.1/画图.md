图的最左侧为多层级业务主体的RAG（检索增强生成）构建示意，纵向排列展示多个业务层级，如：
“企业层 / 工厂层 / 产线层 / 车间层 / 设备层”，
其中仅对“企业层”进行详细展开，其余层级以简化模块表示并不需要额外标注。

“企业内部/外部文档 → 文档加载 → 文本切分 → 向量化编码 → 向量数据库

“企业级大语言模型（Enterprise-level LLM）”，作为全系统的智能中枢：

企业级 LLM 通过 Prompt 从向量数据库中检索最相关的企业知识，用于增强推理与决策能力；
在模型中下部，展示“任务拆分与调度机制”，将复杂业务目标拆分为三个层级子任务。

认知层任务：负责企业知识理解、语义建模、RAG 增强与状态感知；
决策层任务：负责多目标决策、协同优化、策略生成与推理；
执行层任务：负责业务流程编排、系统联动与任务落地执行。
每个层级模块内部包含简要功能说明，体现“认知—决策—执行”的分层结构。
