Training‑time challenges in embedded AI: curation, augmentation,

嵌入式AI的训练时挑战：数据策展、增强和学习


第二章节主要围绕一个之前没有在嵌入式领域计算研究中当作重点的一个瓶颈：训练数据，并解释了它对设计嵌入式人工智能的影响。

数据瓶颈的原因：没有动力像互联网用户发布文本和图像那样大规模地共享传感器数据。
数据瓶颈造成的后果：不能依靠增加模型大小来提供ai能力，而需要改进算法

数据瓶颈的分类：标签（label)稀缺和样本(sample)稀缺

### 1.标签稀缺 (Label Scarcity)

- 问题：传统的监督学习需要大量带标签的数据 。但嵌入式传感器数据（如声学、地震信号）在事后很难被人类准确解读和标记 。
- 原因：
	- 与图像和文本不同，大多数嵌入式传感器数据（如声学、地震信号）在事后是很难被人类解读的 。除非在收集数据的那一刻就详细记录了环境中的所有情况，否则过后仅凭检查传感器波形，是很难标记出当时发生的现象的
	- 时序传感器数据（Time-series sensor data）通常会把“前景物体”（如一个目标）和“背景影响”（如地形）混杂在一起。论文以车辆识别为例。一辆卡车在不同地形（如沙地、泥地、雪地或柏油路）上发出的声音和振动信号会截然不同 。因此，要想训练出一个可靠的AI，就必须从多种不同的环境条件中采集并标记样本 
- 导致的后果 (过拟合 Overfitting)：
	1. 环境敏感性：由于难以获得多样化的标记数据，如果AI模型只用了“不充足”的训练数据，就会导致过拟合 。
	2. 泛化能力差：模型可能在训练环境中表现良好，但一旦环境发生变化（例如，把一个在“一楼公寓”训练的振动传感器移到“高层写字楼”），AI性能就可能急剧下降 。这是因为建筑的“底层结构动力学”改变了，导致相同活动的振动特征也变了 。
	3. 研究方法论陷阱：研究人员经常反复使用已有的公开数据集来迭代开发算法 。这种做法会产生一个“无意的反馈循环” ，导致算法最终过拟合到这个特定的测试集上 。尽管在单次迭代中使用了交叉验证，但这种做法仍会降低研究成果在现实世界中的稳健性

### 2. 样本稀缺 (Sample Scarcity)

- 对策：为了解决“标签稀缺”，研究转向了自监督学习 (Self-supervised learning) 。自监督学习不依赖标签，而是专注于学习输入数据的“潜在表征” 。缓解了对标签的依赖和过拟合问题 。
- “样本稀缺”的定义： 论文紧接着指出，“不幸的是”，在嵌入式系统的上下文中，即便是未标记的数据集 (unlabeled datasets) 也相对较小这就是“样本稀缺”的核心。
- 导致“样本稀缺”的原因： 论文给出了两个主要原因
    - 传感器模态的多样性：嵌入式传感模态（如振动、射频、陀螺仪信号）的种类远比主流AI关注的人类可解释模态（如文本、图像、音频）要多得多 。
    - 缺乏共享基础设施：论文强调，嵌入式领域**缺乏**一个像互联网那样的“广泛的基础设施”，让数十亿的数据源（比如互联网用户）去分享嵌入式传感器数据 。
- “样本稀缺”带来的后果和研究方向：
    - 由于连原始数据都很有限，因此研究的重点必须转向最大化地从有限的可用数据中提取价值，并提高学习效率 。
    - 论文指出，这需要新的方法来：
        - 最大化用于训练的数据的信噪比 。
        - 充分利用传感器数据的特殊特征 。
        - 定制训练流程，以更好地利用这些特性来提高学习效率 。



针对这两个挑战，后续探讨了三个研究方向

2.1（获得干净数据） $\rightarrow$ 2.2（扩充数据量） $\rightarrow$ 2.3（选择模型来学习这些数据）。

### 2.1 嵌入式数据策展 (Embedded data curation)

#### 技术概述 
“数据策展” (Data Curation) 是指评估、筛选和提纯原始传感器数据的过程，以确保用于AI训练的数据是“高质量”和“高信噪比”的 。这在嵌入式AI领域是一个独特且关键的挑战，因为与主流AI（如文本、图像）的数据不同，传感器数据（如测振仪信号）既不可被人类轻易解释，也未被互联网用户“有机地审查”过 。因此，研究人员必须开发自动化的方法来从海量的未标记数据中，区分出“有意义的刺激”和“纯粹的噪音” 。
#### 技术的具体例子

由于缺乏像主流AI那样“有机审查过的高质量嵌入式传感数据库” ，论文指出，一个重要的研究方向是：开发自动化的方法来评估未标记传感器数据的信噪比，以确定数据是否适合用于训练 。

论文提出了几种潜在的解决方案：

1. 利用第一性原理 (First-principle approaches)： ^033d84
    - 利用物理或统计学原理来区分“信号”和“噪音”的统计特性 。
    - 例如，在目标识别中，目标（如车辆）不会“瞬移”。因此，一个有效的信号在频率谱上随时间变化应该是高度相干的，而噪音则可能是独立或弱相关的 。
        
2. 利用领航数据集 (Pilot datasets)：
    - 先收集一个小规模的、干净的“领航数据集” 。
    - 然后利用这个小数据集去过滤更庞大的“开放域数据”，筛选出统计特性上相似的数据 。
        
3. 训练策展模型 (Curation models)：
    - 利用这个“领航数据集”来训练一个专门的AI模型，这个模型的唯一任务就是判断一个新样本“是噪音还是非噪音” 。
        

#### 技术进展（脉络）
论文指出，数据策展问题在很大程度上尚未引起重视 
1. 起点（认识问题）：首先认识到嵌入式AI的数据缺乏主流AI那样的“有机审查”机制，导致数据质量低下 。
2. 当前（提出方向）：进展在于“提出”了需要自动化的解决方案（如上文例子所示），以解决这个“垃圾进，垃圾出”的瓶颈 。


 主流AI的“数据优势”
 
论文首先对比了主流AI（用于人类交流的模态，如文本、视觉、音频）和嵌入式AI的数据差异 。主流AI的数据具有两大优势：
1. 数据是“可解释的” (Interpretable)：
    - 因为数据是人类可解释的，所以在需要时，可以在事后进行标记 (label it in retrospect) 。
2. 数据是“被审查过的” ：
    - 论文提出互联网用户本身充当了一个巨大的“协同过滤器” (collaborative filter)，共同审查了内容 。这使得高质量的数据集（如数字图书馆、新闻门户、热门视频频道）得以涌现 。
    - 一个数据源的流行度 (popularity) 本身就反映了其内容的“信噪比” 。例如，一个充斥着噪音的YouTube频道是不太可能变得流行的 。
 嵌入式AI面临的“策展挑战” (Curation Challenge)
嵌入式AI所依赖的大多数传感器模态（如测振仪、加速度计、射频测量）不具备上述优势。
- 嵌入式数据既不可解释，也不容易被审查 。




### 2.2嵌入式数据增强 (Embedded data augmentation)

#### 1. 技术概述
数据增强的目的是通过生成“假的” (fake) 数据样本来缓解标记数据稀缺的问题 。在嵌入式AI的背景下，使用这一技术是为了增强用于嵌入式系统应用的AI训练 。
然而，嵌入式领域对这项技术有一个核心的特殊要求：由于嵌入式传感器数据反映的是“遵守自然法则的物理系统” ，因此数据增强必须生成高度逼真 (highly realistic) 的样本 。如果生成的“假”数据不切实际（例如，违反了物理定律），那么用它来训练AI模型反而会降低其在现实世界中的表现 。
理想情况下，用于嵌入式AI的数据增强技术应该能体现“领域知识” (domain knowledge) ，并允许对生成信号的“人类可解释特征”（如物理属性）进行“细粒度控制” (fine-grained control) 。


#### 2. 技术的具体例子
论文中提到了两大类数据增强技术及其具体例子：
- 传统数据增强 (Conventional data augmentation)：
    - 这些方法应用人工精心设计的转换来创建现有样本的变体 。
    - 时域 (Time domain) 例子：包括抖动 (jittering)、缩放 (rescaling)、旋转 (rotation) 和裁剪 (cropping) 。
    - 频域 (Frequency domain) 例子：包括频谱翻转 (spectral flipping)、扭曲 (warping) 和掩码 (masking) 。
- 生成式数据增强 (Generative data augmentation)：
    - 这些技术被引入用来合成高度逼真的传感数据 。
    - 技术例子：包括变分自编码器 (VAEs)、生成对抗网络 (GANs) 和扩散模型 (diffusion models) 。
    - 一个前沿例子：论文作者最近提出了一种基于“条件空间插值” (condition space interpolation) 的方法 。


#### 3. 技术进展（脉络）

论文描述了一个清晰的技术进展脉络，从传统方法演进到更高级的生成式方法：

1. 起点：传统方法 (Conventional methods)
    - 这个阶段依赖于应用简单的、人工设计的转换（如抖动、裁剪等） 。
    - 局限性：这些方法生成的样本真实感不足 。它们常常无法捕捉现实信号中存在的微妙高阶相关性 。这在嵌入式领域尤其成问题，因为物理定律严格限制了数据的真实样貌 。
2. 演进：生成式方法 (Generative techniques)
    - 为了克服传统方法的局限性，研究转向了生成式AI技术（如 VAEs、GANs 和扩散模型） 。
    - 目标：不再是简单地“修改”现有数据，而是要“合成”出高度逼真的新数据 ，从而在同一标签下创建具有多样化特征的新样本 。
3. 前沿：可控的生成式方法 (Controllable generative methods)
    - 这是目前一个“相对未被充分探索”的领域，其重点是实现对生成过程的“精确控制” 。
    - 例子：“条件空间插值” 。论文解释说，传统插值（数据层面）可能会在两个位置的图像间产生“重影”，而条件空间插值（条件层面）则会智能地在两个位置之间生成一个“单一”的、处于“插值位置”的图像 。
   

### 2.3 时序数据的模型架构 (Model architecture for time-series data)


#### 1. 技术概述

本节概述了为“多模态嵌入式时序数据” (multimodal embedded time-series data) 选择合适神经网络架构 (neural network architecture) 的挑战 。在数据经过策展和增强之后，下一步就是选择一个能有效从中学习的模型结构 。本节探讨了从早期的监督学习架构，到主流的Transformer架构，再到为解决Transformer的效率瓶颈而设计的最新架构的演进过程。

#### 2. 技术的具体例子

论文中提到了以下几种具体的模型架构：
- 早期的监督学习架构：
    - DeepSense：
    - STFNets：
- 主流的自监督学习架构：
    - Transformer：在更广泛的AI社区中，这是用于自监督学习的最常见的模型架构 7。它使用“注意力机制” (attention mechanism) 来允许模型在“上下文窗口” (context window) 中理解每个数据（标记）的含义 。其核心是“注意力矩阵” (attention matrix) 。
- 新兴的高效架构：
    - 状态空间模型 (SSMs)：这是一种作为Transformer替代品而出现的新架构 。它受到“卡尔曼滤波器” (Kalman Filters) 的启发 。
    - 混合架构 (Hybrid architectures)：结合了SSM层和Transformer层的模型 12。
    - 专家混合 (Mixture-of-experts) 模型：另一种新兴的架构 。
#### 3. 技术进展（脉络）

本节描述了一个清晰的技术演进脉络，其驱动力是对“效率”的追求：
1. 起点 (监督学习)：技术始于为多模态传感器数据**定制的**监督学习架构，如DeepSense（用于时空模式）和 STFNets（用于频域）。
2. 主流 (Transformer)：随着自监督学习的兴起，**Transformer**架构成为主流 16。它通过“自注意力”机制在上下文中解释数据，非常强大 17。
3. 瓶颈 (Transformer的效率问题)：Transformer架构暴露出一个重大缺陷：其“注意力矩阵”的计算量会随着“上下文窗口”长度的平方而增长（$O(n^{2})$）。这种“超线性增长” (superlinear growth) 使其无法高效处理长序列的嵌入式数据 。
4. 演进 (SSMs)：为了解决Transformer的效率瓶颈，研究人员开始探索更高效的架构，特别是状态空间模型 (SSMs) 。SSMs的巨大优势在于，它们随上下文长度增加只产生线性的计算复杂度和恒定的内存空间占用 。
5. 当前前沿 (混合架构)：SSMs本身也有缺陷（例如在需要长上下文理解的任务上表现不佳）。因此，最新的进展是混合架构（结合SSMs和Transformers的优点）和“专家混合” (mixture-of-experts) 模型 




### 2.4从嵌入式数据中进行自我监督学习
这一节论述了既然嵌入式AI面临数据瓶颈（标签稀缺和样本稀缺），那么出路就在于自监督学习 (SSL)。
1. SSL 如何解决“标签稀缺”
    - “标签稀缺”的困境在于传统的“监督学习”必须依赖海量的、带标签的数据（即“输入-答案”对）来进行训练 。
    - 在嵌入式领域，获取这些标签极其困难且昂贵（例如，人类难以在事后解读传感器波形） 。
    - SSL 的“出路”在于它从根本上“减少了对标签数据的依赖” 。它转而利用那些更容易获得的未标记数据 (unlabeled data) 。
---

对于第二个瓶颈“样本稀缺” (Sample Scarcity)，
论文指出，转向 SSL 之后，我们虽然不再需要标签了，但“不幸的是”，在嵌入式领域（由于传感器模态多样且缺乏共享基础设施）连“未标记的”数据样本本身都很稀少 。
这意味着，主流AI可以依赖海量的未标记数据（如整个互联网的文本和图像）来训练 SSL，但嵌入式 AI 没有这个条件。
 既然连未标记的数据都很少（样本稀缺），那么“出路”就是“怎么学得更高效”。
论文明确指出，这要求嵌入式 AI 的训练流程“必须变得更善于从相对有限的可用训练数据中提取价值” 。
这就是为什么前三节（2.1到2.3）都在为这个目标服务：
1. 最大化信噪比（通过 2.1 数据策展）。
2. 扩充数据（通过 2.2 数据增强）
3. 利用更高效的模型（通过 2.3 模型架构）

#### 1. 技术概述

“自监督学习” (SSL) 是一种AI训练范式，其目标是最大化地从有限的、未标记的数据中提取价值 。文中提到自监督学习是一个“编码问题” (encoding problem) 。它的核心目标是学习数据本身的‘表征’ (Representation)，核心工作则是一个‘编码问题’ (Encoding Problem)
- AI（即‘编码器’）会读取海量的、未标记的原始数据 ，比如一段复杂的传感器信号。
- 它的目标是学会如何将这段信号‘编码’成一个简洁的、机器可理解的摘要，这个摘要就是它的‘潜在表征’ (latent representation) 。
- 这个‘编码’的目标是让这个摘要的存放空间变得‘语义组织良好’ (semantically well-organized) 。（在这个‘潜在空间’（也就是存放这些摘要的地方）里，含义相似的信号，它们的摘要也彼此靠近 ）
	例子：所有代表‘卡车经过’的振动信号，无论它们来自沙地还是雪地，它们的摘要都应该聚集在‘潜在空间’的同一个区域。而‘风声’的摘要，则应该被放在另一个很远的区域。AI需要通过自学，自己领悟出了‘卡车’和‘风声’是两个不同的概念。
这个工作一旦完成，好处是巨大的。当这个AI训练好后（编码器学会了如何正确聚类这些摘要），下游的任何具体任务（比如‘分类’或‘定位’）都会变得极其简单
我们不再需要一个复杂的模型，我们只需要一个非常简单的‘解码器’——论文提到甚至一个‘单层线性解码器’就足够了 ——就能读取这些分门别类的摘要并完成任务
但是，论文强调，我们不能直接照搬主流AI的‘编码方法’。因为嵌入式数据有四大特性（多模态、频域、多视角、配置空间），这让我们的‘编码’工作（SSL）变得异常困难

#### 2. 技术进展（脉络）
从“通用的SSL”演进到“为嵌入式特性深度定制的SSL”。这个演进过程是围绕解决2.4节引言中提到的四大挑战 展开的，这四大挑战也构成了四个小标题：
2.4.1 容纳多模态数据 (Accommodating multimodal data)
- 问题在于：嵌入式AI需要的是‘智能融合’(Modality Fusion)。主流AI做的是‘模态转换’，比如把图像转成文字。而在嵌入式领域我们需要的是把不同传感器的信息‘捏合’在一起，以获得更深的理解。”
- 论文中具体的例子：一个毫米波雷达 (mmWave radar) 可能识别出一个物体是‘18轮卡车’ 。而一个振动传感器 (vibration sensor) 可能根据振动谐波，估算出它‘是否载重’ 。同时，像‘卡车速度’这样的属性，则可能从两个传感器中都能被推断出来 。”而一个好的融合模型不应该‘冗余地编码’ (redundantly encode) 共同信息（如速度）。论文探讨了一种对比学习框架 ，它将多模态信号联合嵌入到一个潜在空间。这个空间被结构化地划分为：
1. 共享维度 (Shared dimensions)：用于‘非冗余地’ (non-redundantly) 表征跨传感器的共同信息 。
2. 模态特定维度 (Modality-specific dimensions)：用于表征单一传感器‘私有的’ (private) 额外信息 。”
2.4.2 容纳频域特征 (Accommodating frequency domain signatures)
- 问题：AI在自学时，必须被引导去关注信号，而不是噪音。但我们在自监督学习中又没有标准答案，2.4.2讨论的就是这个问题
- 论文的方案是：利用‘物理学’来指导AI。”
- 首先，AI不能把传感器数据（比如频谱图）当作一幅普通的‘风景画’。在风景画里，一只猫在左上角还是右下角，它都是猫。但在传感器的‘频谱图’（我们可以理解为信号的‘音高’分布图）里，一个信号出现在‘高音区’还是‘低音区’，它的物理含义是完全不同的（比如代表快或慢）。”
- 其次，我们用物理指标来帮AI区分‘重点’和‘噪音’：
1. 高能量：告诉AI，信号能量突然剧烈变化的地方，很可能是‘重点’。
2. 高相干性：它源于物理上的‘惯性’。真实世界的大型物体（比如一辆车）是有惯性的，它发出的信号随时间变化一定是‘连续且稳定’的（即高相干性）。而噪音则是杂乱无章的。”
“最终目的：通过这些物理指标，AI在‘自学’时（无论是用对比学习还是掩码），就会被引导去重点关注那些‘高能量’或‘高相干性’的区域，从而更高效地学习，避免被噪音带偏。”

2.4.3 多视角数据的空间推理 (Spatial reasoning from multivantage data)
问题：
1. 数据结构非传统：自监督学习的主流应用（如语言和视觉）处理的是结构化数据，如1D序列（文本）或2D规则阵列（图像）。
2. 采样方式的根本差异：嵌入式系统的一个重要特性是“在不同位置存在多个传感器”，它们提供了“互补的视角” 。这构成了对环境的一种“稀疏、不规则、多模态采样” (sparse irregular multimodal sampling)，这在主流AI中没有直接的类似物 。
3. 复杂的相关性：与像素或单词不同，传感器具有复杂的“位置和关系” 。例如，“附近的传感器”可能是“冗余的”，而“相距较远的”可能是“互补的”，“距离足够远的”则可能“不相关” 。
4. 需要长期状态与时空推理：模型必须能够自动学习“重要的状态” 。论文给出了一个具体的例子：要断言“一栋大楼是空的”，AI需要“长期记忆谁进入和离开了它” 。这种对长期时空状态的理解，对简单的SSL模型构成了巨大挑战。
解决方法：
- 重新思考编码器架构：必须“重新思考自监督编码器架构”，使其适用于“空间分布的传感器数据流” 。
- 新的架构目标：新架构必须能够生成“更好地反映环境状态”的嵌入 (embeddings)，并帮助“解决时空推理问题”

2.4.4 庞大的传感器与环境配置空间 (The large sensor an environment configuration space)
- 问题：
	- “配置空间”是庞大的：在现实世界中，传感器部署的“配置” (configuration) 组合几乎是无限的。这包括传感器的类型、型号、部署位置、采样率 (sampling rates) ，以及传感器所处的环境（例如，是高层建筑还是停车场 ）
	- AI模型与配置的“耦合” (Coupling)：AI模型往往会将其学到的“潜在表征”（即对世界的理解）与训练时所用的“配置空间”紧密“耦合” (coupled) 在一起 。
- 这导致的后果是：导致模型缺乏稳健性。如果将AI部署到与训练时配置不同的新环境中（例如，换了一个不同“采样率”的传感器 ，或者换了一个不同的部署位置），模型就可能会失效。为这个“庞大的配置空间”中的每一种可能性都训练一个新模型是不切实际的。
- 解决方案“解耦” (Decouple)：为了解决这个由“庞大配置空间”带来的挑战，论文指出，一个理想的特性 (desired property) 是设计出能够“将个别传感器的特性与下游分析解耦”的SSL架构 。
