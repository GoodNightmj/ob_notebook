# 大模型数学基础

> 这一节主要对应 Transformer 中最常见的线性代数概念：向量、矩阵、范数、点积、余弦相似度、线性层和注意力分数。

## 1. Embedding：把 Token 映射成向量

Embedding 可以理解为：把离散的文本单位（Token）映射成计算机可以处理的稠密向量。

在大模型中，输入文本会先被分词器切成 Token，然后每个 Token 都会查表得到一个向量。例如：

```text
"苹果" -> [0.12, -0.35, 0.87, ...]
```

这些向量不是人工指定的，而是在训练过程中学习出来的。训练得好时，语义相近的词或 Token，向量在空间中的位置通常也会更接近。

### 为什么用向量，而不是一个数字？

一个单独的数字通常只能表示一个维度，而且 Token ID 本身只是编号，不天然表示语义关系。

向量可以有很多维度，每个维度都可能承载一部分语义特征。维度越多，模型就越有能力表达更丰富的语义信息。

## 2. 语义空间

语义空间可以理解为一个高维的数学空间。Embedding 把 Token 变成向量后，每个 Token 就像这个空间中的一个点。

在这个空间里，常见的直觉是：

- 语义相近的 Token，向量距离通常更近；
- 语义差异大的 Token，向量距离通常更远；
- 这种关系不是人工规定的，而是模型训练后逐渐学出来的。

注意：这不是绝对铁律，而是训练目标、数据质量和模型能力共同作用下形成的统计规律。

## 3. 向量范数：向量有多长

向量范数可以理解为向量的长度。最常用的是二范数：

$$
\|a\|_2 = \sqrt{a_1^2 + a_2^2 + \cdots + a_n^2}
$$

它衡量的是向量本身的大小，而不是两个向量之间的相似度。

## 4. 点积与余弦相似度

两个向量 $a$ 和 $b$ 的点积为：

$$
a \cdot b = \sum_i a_i b_i
$$

点积和夹角之间的关系是：

$$
a \cdot b = \|a\|_2 \times \|b\|_2 \times \cos(\theta)
$$

因此，余弦相似度可以写成：

$$
\cos(\theta) = \frac{a \cdot b}{\|a\|_2 \times \|b\|_2}
$$

### 怎么理解？

- 如果两个向量方向越接近，$\cos(\theta)$ 越接近 1；
- 如果方向越相反，$\cos(\theta)$ 越接近 -1；
- 如果方向接近垂直，$\cos(\theta)$ 接近 0。

点积可以用来衡量相关性，但它会受到向量长度影响。因此，如果想更纯粹地比较方向相似度，通常会使用余弦相似度。

## 5. 矩阵：很多向量排在一起

矩阵可以理解为很多个向量排列在一起。

在 Transformer 中，常见约定是：

$$
X \in \mathbb{R}^{n \times d}
$$

其中：

- $n$ 表示 Token 数量；
- $d$ 表示每个 Token 的向量维度；
- $X$ 的每一行通常对应一个 Token 的 embedding 或 hidden state。

例如一句话有 4 个 Token，每个 Token 是 8 维向量，那么输入矩阵形状就是：

```text
X: (4, 8)
```

## 6. 神经网络中的线性层

线性层的公式是：

$$
Y = XW + b
$$

其中：

- $X$ 是输入矩阵；
- $W$ 是权重矩阵；
- $b$ 是偏置；
- $Y$ 是输出矩阵。

线性层的作用是把向量从一个特征空间映射到另一个特征空间。

例如：

```text
X: (4, 8)
W: (8, 16)
b: (16)
Y: (4, 16)
```

这里表示：4 个 Token 仍然是 4 个 Token，但每个 Token 的表示从 8 维变成了 16 维。

注意：维度从 8 变成 16，不等于“向量长度一定变长”，而是表示特征维度变多了。向量长度指的是范数，和维度数量不是一回事。

## 7. Transformer 中的 Q、K、V

在 Transformer 的自注意力机制中，会用三个线性层把输入 $X$ 分别映射成：

$$
Q = XW_Q
$$

$$
K = XW_K
$$

$$
V = XW_V
$$

其中：

- $Q$ 是 Query，表示“当前 Token 想找什么信息”；
- $K$ 是 Key，表示“每个 Token 能被别人匹配到的特征”；
- $V$ 是 Value，表示“真正要被加权汇总的信息”。

## 8. 为什么要转置 K？

假设：

```text
Q: (n, d_k)
K: (n, d_k)
```

其中 $n$ 是 Token 数量，$d_k$ 是 Query/Key 的维度。

如果要计算每个 Query 和每个 Key 的相似度，需要让 $Q$ 的每一行去和 $K$ 的每一行做点积。矩阵乘法中需要写成：

$$
\text{scores} = QK^T
$$

对应形状是：

```text
Q:        (n, d_k)
K^T:      (d_k, n)
scores:   (n, n)
```

所以 scores 是一个 $n \times n$ 的表格：

- 第 $i$ 行表示第 $i$ 个 Token 作为 Query；
- 第 $j$ 列表示第 $j$ 个 Token 作为 Key；
- $\text{scores}_{i,j}$ 表示第 $i$ 个 Token 对第 $j$ 个 Token 的关注程度。

在实际 Transformer 中，通常还会做缩放：

$$
\text{scores} = \frac{QK^T}{\sqrt{d_k}}
$$

然后经过 softmax 变成注意力权重，再用这些权重对 $V$ 做加权求和。

## 9. 一个小例子

假设句子是：

```text
我 / 吃 / 苹果
```

如果想看“吃”这个 Token 对“苹果”这个 Token 的关注程度，就要看：

```text
scores["吃", "苹果"]
```

也就是：

- “吃”的 Query 向量；
- “苹果”的 Key 向量；
- 两者做点积，得到注意力分数。

分数越大，通常表示当前 Token 越关注那个 Token。但最终还要经过缩放、softmax 和 Value 加权，才会得到注意力层的输出。
