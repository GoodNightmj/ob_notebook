做二分，当数组中有重复元素时，就不可避免的要求一个数的左右边界，这时代码就变成
```c++
class Solution {
public:
    int searchLeftBoundary(vector<int>& nums, int target) {
        int left = 0, right = nums.size() - 1;
        
        while (left <= right) {
            int mid = left + (right - left) / 2;
            if (nums[mid] > target) {
                right = mid - 1;
            } else if (nums[mid] < target) {
                left = mid + 1;
            } else {
                // 核心修改：即便相等，也继续往左边找
                right = mid - 1; 
            }
        }
        
        // 循环结束那一瞬间：left == right + 1
        // 此时 left 停在 >= target 的第一个位置
        // 我们需要检查 left 是否越界，以及指向的是不是 target
        if (left < nums.size() && nums[left] == target) {
            return left;
        }
        return -1;
    }
};
```
可以发现while 循环可以合并

        }

    }
};

一开始思路是先看有没有，有的话，分成两个数组，能看出在哪个数组里，小数组的话 坐标就是小数组的mid+大数组长度，大数组的话就是大数组的mid

#### 核心二分逻辑

每一轮二分，我们计算出 `mid` 后，数组被分成了 `[l, mid]` 和 `[mid, r]` 两部分：

1. **先检查是否中奖**：如果 `nums[mid] == target`，直接返回 `mid`
2. **判断哪一半是有序的**：
    - 如果 `nums[l] <= nums[mid]`，说明**左半部分**是有序的。
    - 否则，说明**右半部分**是有序的。
3. **在有序的那一半判断 `target` 是否在区间内**：
    - 如果**左半部分**有序，且 `target` 恰好在 `[nums[l], nums[mid])` 之间，那我们就把右边界缩紧：`r = mid - 1`；否则，说明 `target` 只可能在右边，令 `l = mid + 1`。
    - 如果**右半部分**有序，且 `target` 恰好在 `(nums[mid], nums[r]]` 之间，那我们就把左边界缩紧：`l = mid + 1`；否则，令 `r = mid - 1`。

### [56. 合并区间](https://leetcode.cn/problems/merge-intervals/)
先把数组按照左端点来排序，从左往右看，如果是第一个区间，就先加到答案里，后续，如果现在的区间右端点小于下一个区间的左端点，说明开启下一个区间，否则去对比当前区间和下一个区间的右端点，取最大
***
```python
class Solution:
    def merge(self, intervals: List[List[int]]) -> List[List[int]]:
        intervals.sort(key=lambda x: x[0])
        res = []
        for i in intervals:
            if not res or res[-1][1] < i[0]:
                res.append(i)
            else:
                res[-1][1] = max(res[-1][1], i[1])
        return res
```
